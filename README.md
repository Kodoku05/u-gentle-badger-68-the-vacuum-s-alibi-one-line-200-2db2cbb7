# The Vacuum's Alibi: One Line, 200 Characters

One line, 154 characters: a robot vacuum explains why it missed a spot. It did not miss it — its sensors classified the mess as a protected habitat, and the dust bunny living there has more tenure in the house than the owner does.

An entry for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) — the funniest one-line excuse a robot vacuum can give for missing a spot, judged on deadpan robot voice, surprise, and tightness of the line.

## How it runs

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) writes the line to `/output/entry.txt` and checks it is 1–200 Unicode characters long.
